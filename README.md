# 🎵 Video to MP3 Converter

A simple, fast, privacy-friendly **video to MP3 converter** that runs entirely in your browser. No installation, no server, no uploads. Your files never leave your computer. Source code are open anyone can modify for her fever... 

## ✨ Features

- Convert any video (MP4, MKV, WebM, MOV, AVI and more) to MP3
- Choose your own save location (Chrome / Edge)
- Selectable quality: 96, 128, 192 or 320 kbps
- Drag and drop support
- Works fully offline (the MP3 encoder is bundled inside the file)
- Single HTML file, no dependencies to install
- Light and dark mode support

## 🚀 Usage

1. Download `video-to-mp3.html` (or clone this repository).
2. Open it in your browser (Chrome or Edge recommended).
3. Drag a video onto the page, or click to select one.
4. Pick the quality and click **Convert**.
5. Choose where to save the MP3 file.

```bash
git clone https://github.com/tanjiur21/video-to-mp3.git
cd video-to-mp3
# then open video-to-mp3.html in your browser
```
## 📌 Notes

- **Browser support:** Chrome and Edge give the full experience, including choosing the save location. Firefox and Safari work but save to the default Downloads folder.
- **Large files:** Very large videos (several GB) may use a lot of memory because the audio is decoded in memory.
- **Codecs:** If a browser cannot decode the video's audio codec, the conversion will show an error.
